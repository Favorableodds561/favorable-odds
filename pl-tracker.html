Categories & Tax Treatment

Every category is mapped to a line on the return this client actually files. The mapping follows the chain entity → federal tax classification → return → form line, so the same category lands in different places for an S-corp and a sole proprietor. The audit below flags anything that would misstate taxable income — draws or loan principal being deducted, transfers booked as revenue, a category used on both sides of the books, meals at 100%, officer pay mixed into ordinary wages. Settings are per-client.

🎯 Categorization Rules

Bank descriptions repeat every month, so categorizing them by hand is both the slowest part of a close and the main source of miscoding — the same vendor coded one way in March and another way in May. A rule fixes that mapping once: on the Import Statement review screen every matching row arrives pre-categorized and flagged, so you only review what didn't match. Rules are per-client and never import anything on their own — they only preselect the category, and you still click to add each row.

🛟 Backup & Snapshots

All transaction data is stored in this browser on this computer. Clearing site data, resetting the browser, or moving to a new machine erases it. The downloaded backup file is the only copy that survives any of those — keep it somewhere off this machine (Google Drive, or emailed to yourself).

Issues Center

Every unresolved finding from the category audit, the ledger and form reconciliations, the rule risk flags and the filings held-out balances, in one severity-ranked list. Issues are recalculated from the data each time — correct the source and the issue disappears. Only your decisions persist, and deferring or accepting one requires a reason that stays in the audit history.
