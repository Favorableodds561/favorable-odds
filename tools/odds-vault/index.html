    The basics

    What is file metadata?

    Metadata is information stored inside a file in addition to what you see when you open it. A photo shows a picture, but the file may also record when and where it was taken and on which device. A document shows text, but its properties may record who wrote it, who saved it last, and which software produced it.

    Most people never see this information, and most sharing apps and email clients pass it along unchanged. Common examples include:

    • Author nameThe person or account that created the file.
    • Creation and modification datesWhen the file was made and last saved.
    • Software usedThe app and version that created or exported it.
    • GPS coordinatesWhere a photo was taken, stored in its EXIF data.
    • Camera informationDevice make and model, and capture settings.
    • Document propertiesTitle, subject and keywords fields.
    • Company and manager fieldsOrganization details stored in Office documents.
    • CommentsText notes embedded in the file or attached to it.
    • Preview thumbnailsSmall copies of the content saved inside the file.

    Good habits

    Why remove metadata?

    Checking a file before you send it is like checking who is on the email thread. A few everyday reasons to do it:

    • Privacy before sharing photos. Photos can carry the time, the device and often the exact location where they were taken.
    • Removing author information from documents. Word, Excel and PowerPoint files record who created and last modified them.
    • Preventing accidental location sharing. A photo of something you are selling from home can reveal your address through its GPS data.
    • Cleaning business files before sending them externally. Company and manager fields, software details and preview thumbnails rarely need to travel with a proposal or invoice.
    • Reducing unnecessary identifying information. Sharing less by default is a simple, sensible privacy practice.

    Metadata removal is a privacy habit for the files you own and share. It is not a way to avoid accountability, and it does not change what your files say.

    Supported formats

    What Odd$ Vault can clean

    Odd$ Vault edits a copy of each file inside your browser. Your originals are never changed. Here is what it looks for in each format, and what it leaves alone.

    JPEG / JPG photos

    Removes

    • EXIF data: camera and device details, date and time, embedded preview thumbnail, and GPS location
    • XMP and IPTC/Photoshop data, embedded comments and other application-specific data blocks

    Keeps

    The image itself (it is not re-compressed), the standard JPEG header and the color profile. Extra data attached after the end of the image, such as the video in some "motion photos", is not removed. EXIF also holds the orientation flag, so some phone photos may show rotated afterward.

    PNG images and screenshots

    Removes

    • Text chunks (including embedded XMP), the EXIF chunk, the last-modified timestamp and digital-signature chunks

    Keeps

    Image data, color information and other structural chunks.

    WebP web images

    Removes

    • EXIF and XMP metadata chunks

    Keeps

    Image data and color profile.

    PDF documents

    Removes

    • Document information fields: title, author, subject, keywords, creator, producer, creation date and modification date
    • The document-level XMP metadata

    Keeps

    Page content. It does not edit text, annotations, attachments or form data, and it cannot open password-protected PDFs.

    DOCX Word

    Removes

    • Core properties: author, last modified by, title, subject, keywords and dates
    • Extended properties: company, manager and application details
    • The preview thumbnail

    Keeps

    Document content, plus items stored elsewhere in the file: comments, tracked changes, custom properties, and images embedded in the document.

    XLSX Excel

    Removes

    • Core and extended properties (author, last modified by, company, manager, dates, application details)
    • The preview thumbnail

    Keeps

    Sheet content, including hidden sheets, comments and custom properties.

    PPTX PowerPoint

    Removes

    • Core and extended properties (author, last modified by, company, manager, dates, application details)
    • The preview thumbnail

    Keeps

    Slide content, speaker notes, comments and custom properties.

    Word, Excel and PowerPoint have their own built-in checker (File › Info › Check for Issues › Inspect Document) for comments, tracked changes and hidden content. Run it on important files in addition to Odd$ Vault.

    Be realistic

    What Odd$ Vault does not do

    Removing metadata does not make anyone anonymous. It only clears certain hidden fields. A file can still point to you in many other ways.

    It does not anonymize content

    Faces, names, visible text, screenshots, logos, writing style and the contents of a document can all identify a person or organization, and Odd$ Vault does not touch them.

    It does not rename your files

    File names often contain names, dates or client details. The "hide file names" option keeps them out of the outer ZIP listing, but the names are still inside the archive. Rename files first if the name itself is sensitive.

    Unsupported files keep their metadata

    If you choose to include file types Odd$ Vault can't clean, they go into the ZIP untouched and keep whatever metadata they have.

    It does not clean everything inside a file

    Comments, tracked changes, custom properties, PDF annotations and attachments, images embedded inside documents, and extra data attached to the end of a JPEG (such as motion-photo video) are not cleaned.

    It can't prove a file is fully clean

    The report lists what was found and removed. It cannot show that no other identifying information remains, so review important files yourself before sharing.

    It can't recover your password

    The password is used in your browser and never sent to us. If you lose it, the ZIP cannot be opened. A short or guessable password also weakens the encryption, so consider using the built-in generator.

    Questions

    Odd$ Vault FAQ

    Is Odd$ Vault free?

    Yes. Odd$ Vault is free to use. There is no account, no email signup and no usage counter. The only limits come from your own browser and device, because files are processed in your device's memory.

    Are my files uploaded?

    No. Your files are read and cleaned by JavaScript running in your browser, and the encrypted ZIP is created on your device and saved through your browser's normal download. Odd$ Vault contains no upload code, and the page is configured to block itself from making network requests. Favorable Odds does not receive or store your files or your password. Opening the page does load the page itself and its fonts over the web, like any website.

    What metadata can Odd$ Vault remove?

    It removes common metadata from JPEG, PNG, WebP, PDF, DOCX, XLSX and PPTX files: EXIF (including GPS location and camera details), XMP and IPTC data and embedded comments in images; document information fields and XMP metadata in PDFs; and author, last modified by, company, manager, dates, application details and preview thumbnails in Word, Excel and PowerPoint files. See what Odd$ Vault can clean for each format and for what it leaves alone.

    Can it remove GPS information from photos?

    Yes, for JPEG photos. Odd$ Vault removes the whole EXIF block, which is where GPS coordinates are stored, along with the camera model, timestamps and embedded thumbnail. It also removes XMP data. PNG and WebP images have their EXIF data removed the same way. HEIC photos, the default on many iPhones, are not supported, so convert them to JPEG first. After cleaning, the report shows whether GPS location was found and removed.

    Can it remove metadata from PDFs?

    Yes. It clears the PDF's document information fields (title, author, subject, keywords, creator, producer, creation date and modification date) and its document-level XMP metadata. It does not edit page content, annotations, attachments or form data, and it cannot open password-protected PDFs.

    Can it remove metadata from Word documents?

    Yes, for .docx files. Odd$ Vault clears the core properties (such as author, last modified by, title and dates) and extended properties (such as company, manager and application details), and removes the preview thumbnail. It does not remove comments, tracked changes, custom properties or hidden text, and it does not clean images embedded in the document. Older .doc files are not supported.

    Does removing metadata make a file anonymous?

    No. Removing metadata only clears hidden fields in the file. Faces, names, visible text, screenshots, logos, writing style, file names and the contents of a document can still identify you or your organization. See what Odd$ Vault does not do.

    What file types are supported?

    Odd$ Vault cleans JPEG/JPG, PNG, WebP, PDF, DOCX, XLSX and PPTX files. Other types, such as HEIC, GIF, TIFF, video, or older .doc, .xls and .ppt files, cannot be cleaned. You can still add them to the ZIP by ticking “Also include files Vault can't clean”, but they keep whatever metadata they have.

    Why can't Windows open my encrypted ZIP?

    Odd$ Vault encrypts the ZIP with AES-256, and the built-in Windows ZIP extractor does not support AES-encrypted ZIP files. Open it with a free tool such as 7-Zip or WinRAR on Windows, or Keka on a Mac. If you left “Hide file names inside the zip” on, extracting gives you a single file called contents.zip, which opens normally and holds your cleaned files.

    Can Favorable Odds recover my password?

    No. Your password is used in your browser to encrypt the ZIP and is never sent to or stored by Favorable Odds, so there is nothing for us to recover. If you lose it, the files in the ZIP cannot be opened. Save it in a password manager before you download.

    Will cleaning change how my photo or document looks?

    Your original files are never modified; only cleaned copies go into the ZIP. Images are not re-compressed, so quality is not reduced. One visible side effect: EXIF also stores photo orientation, so some phone photos may appear rotated after cleaning. PDFs and Office files are re-saved by the tool, so their file size can change slightly.
