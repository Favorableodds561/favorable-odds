Trust and transparency

Check it before you run it

A cleanup tool deletes files, so you should be able to verify it. The program is open source and every build is hashed.

Verify the download

After downloading, compare the file's SHA-256 with the one in the release details. In PowerShell:

Get-FileHash .\OddsTune.exe -Algorithm SHA256

Or in Command Prompt:

certutil -hashfile OddsTune.exe SHA256

If the values differ, don't run it. A hash confirms the file wasn't damaged or swapped after it was published; it can't vouch for a website that has itself been compromised.

Not code-signed yet

Version 1.0.0 is unsigned: it has no code-signing certificate. Windows SmartScreen or your antivirus may warn you that the publisher is unknown, because the file is new and unsigned.

We will not describe it as signed until it is. If a signed build is published later, it will have a new SHA-256.

Read the source

The full source code, the cleanup rules and the automated tests are public. Each build runs the tests on Windows and Linux before the executable is created, then starts the built program once as a self-check.

Why it may ask for administrator permission

Scanning and cleaning your own temporary files needs no special rights. Cleaning the protected Windows Temp and Windows Error Reporting folders, optimizing the drive, and running DISM and SFC need Administrator permission.

Odd$ Tune explains why before Windows asks, and you can say No. Declining changes nothing.

What it does

Core features

Removes eligible temporary files and provides access to documented Windows maintenance and repair functions. It does not promise a faster PC.

PC Health Scan

A read-only look at your PC: Windows version and build, CPU, RAM, system drive free and used space, SSD or hard-disk type where Windows reports it, pending restart, how much storage is eligible for cleanup, the Recycle Bin's size, administrator status, and whether the Windows repair tools are present. Measurable facts only: no "health score".

Safe Cleanup

Pick from a short list of known temporary and cache locations. You see the estimated space before you confirm and the space actually recovered afterwards, including how many items were skipped.

Startup Review

Opens Windows' own Startup Apps page. You decide what runs at sign-in. Odd$ Tune never turns a startup program off for you.

SSD/HDD-aware Drive Optimization

Runs Windows' defrag <drive> /O on your Windows drive, so Windows chooses the right operation for the drive type: retrim for an SSD, defragmentation for a hard disk.

Advanced Windows Repair

A separate, deliberate action for Windows problems: DISM /Online /Cleanup-Image /RestoreHealth, then sfc /scannow. Live output, exit codes and a saved log. It is a repair tool, not a speed booster.

Local Reports

HTML and JSON reports saved on your PC: before and after space, what was found and removed, what was skipped and why, and operation results. They don't include your computer or user name.

Cleanup rules

Exactly what Odd$ Tune cleans

Cleanup is allowlist-based. It looks only inside these locations and only at files that are old enough. It never searches your profile for .tmp or .log files.

Recent files are protected

A file is only eligible if it is old by both its modified time and its creation time, so freshly extracted installer files are left alone.

Links are never followed

Symbolic links, junctions and other redirected folders are skipped, so cleanup can't wander outside the folders listed above.

Locked files are skipped

Files in use by Windows or an app are skipped and counted. One locked file never stops the rest of the cleanup.

Unusual folders are skipped

If your TEMP setting points somewhere unusual, such as a drive root or your Documents folder, Odd$ Tune ignores it for safety and says so.

Deliberately left out

What Odd$ Tune does not do

Many "PC optimizers" do things that can cause problems. Odd$ Tune is intentionally not one of them.

  • No registry cleaning
  • No "RAM boosting"
  • No disabling Windows services or scheduled tasks
  • No automatic disabling of startup programs
  • No driver updating
  • No browser history, cookies or password cleaning
  • No scanning your whole profile for .tmp, .temp or .log files
  • No uninstalling software
  • No telemetry, analytics, ads or background services
  • No upload of reports or scan results

It also does not remove malware and is not a replacement for antivirus. If you suspect someone else has access to your PC, our free Odd$ Guard audit shows remote-access software, extra administrators and weakened security settings.

Know the difference

Cleanup is not repair

Cleanup (Safe Cleanup tab)

Removes eligible old temporary files to free storage. It is optional, routine and changes only the allowlisted locations. It never runs repair tools.

Repair (Maintenance tab)

DISM and System File Checker are Windows integrity tools for corruption, crashes, errors or damaged system components. They are not speed boosters and can take a long time. DISM may use Windows Update to fetch replacement components. Odd$ Tune only runs them when you ask.

Simple by design

How Odd$ Tune works

  1. Download and run

    There is no installer. Download OddsTune.exe, verify its hash if you like, and double-click it.

  2. Scan My PC

    A read-only scan. Nothing is deleted or written, and no report is created unless you ask for one.

  3. Review

    See what could be cleaned and how much space it is, category by category.

  4. Choose and confirm

    Tick only what you want. The Recycle Bin is off unless you tick it. Confirm and cleanup runs.

  5. Check the report

    A before and after report is saved locally. Maintenance actions open their own window with live output and a saved log.

Privacy

Your PC stays your business

Odd$ Tune runs entirely on your computer. It has no account system, no telemetry or analytics, no upload code and no auto-update, and the project's automated tests fail if a networking library is added to the program. Reports stay on your PC in Documents\Favorable Odds\Odd$ Tune Reports unless you choose to share them, and they don't record your computer name or user name.

The program's "open web page" button launches your normal browser only when you click it. When you run Advanced Windows Repair, DISM is a Windows component that may contact Windows Update to obtain replacement files; that is Windows, not Odd$ Tune.

Questions

Odd$ Tune FAQ

Is Odd$ Tune free?

Yes. Odd$ Tune is free to download and use. There is no account, no sign-up and no ads.

Is it safe? Will it delete my personal files?

Odd$ Tune only cleans a short allowlist of Windows temporary, cache and error-report folders, and only files older than a minimum age (48 hours, 72 hours or 7 days depending on the folder). It does not touch Documents, Desktop, Downloads, Pictures or your browser data. It scans first, shows what it found, and deletes nothing until you choose categories and confirm. See exactly what Odd$ Tune cleans.

What exactly gets deleted?

Old files in your user Temp folder, crash dumps, the DirectX shader cache, the Windows Temp folder, and queued or archived Windows Error Reporting files, plus the Recycle Bin only if you tick that option. Recent files, locked files, and anything reached through a link or junction are skipped.

Will Odd$ Tune make my PC faster?

It can free storage by removing eligible temporary files, and it gives you access to documented Windows tools, but we don't promise a speed-up and the app doesn't invent a performance score. Many slow PCs are slow for reasons cleanup can't fix, such as too many startup apps, an almost-full drive or aging hardware. That's why it includes a shortcut to Windows' Startup Apps page and shows your free disk space as a measurable fact.

Does Odd$ Tune upload anything or collect telemetry?

No. It runs locally, has no telemetry, analytics, account system or upload code, and its automated tests fail if a networking library is added. Reports are saved on your PC and are not uploaded. Choosing to open the web page launches your browser; running Advanced Windows Repair may use Windows Update through DISM, which is a Windows component.

Why does Windows show a security warning when I run it?

Version 1.0.0 is not code-signed, so Windows SmartScreen or your antivirus may warn that the publisher is unknown. Verify the SHA-256 hash on this page before running it, and read the open-source code if you like. See check it before you run it.

Why does it ask for administrator permission?

Scanning and cleaning your own temp files doesn't need it. Cleaning the protected Windows Temp and Windows Error Reporting folders, optimizing the drive, and running DISM and SFC do. Odd$ Tune explains why before Windows asks, and if you choose No, nothing starts and nothing is changed.

Is drive optimization safe for an SSD?

Odd$ Tune runs Windows' own defrag command with the /O switch, which tells Windows to perform the optimization appropriate to the drive type: a retrim for an SSD and defragmentation for a hard disk. It does not run a traditional defragmentation on an SSD.

What are DISM and SFC, and when should I use them?

DISM and System File Checker are Windows repair tools that check for and repair damaged system files and the Windows component store. Use them if Windows shows errors, crashes or seems corrupted, not as routine maintenance or a speed boost. Odd$ Tune runs DISM first, then SFC, shows the live output and saves a log. It never runs them during an ordinary cleanup.

Which versions of Windows are supported?

Windows 11 on 64-bit (x64) PCs is the primary target, and Windows 10 64-bit is best effort. ARM64 and 32-bit Windows are not supported. Automated tests and the build run on a Windows x64 runner.

Where are the reports saved, and what do they contain?

In Documents\Favorable Odds\Odd$ Tune Reports as HTML and JSON files (maintenance runs also save a text log). They list the Windows version, CPU, RAM, disk space, what was found and removed, what was skipped and why, and operation results. They don't record your computer name or user name, and nothing is uploaded.

Does it remove malware, clean the registry or clear my browser?

No. Odd$ Tune is not an antivirus or malware remover, and it deliberately has no registry cleaner, RAM booster, service disabling, driver updater or browser-data cleaning. If you're worried someone else can access your PC, try Odd$ Guard.

How do I uninstall it?

There is nothing to uninstall: Odd$ Tune is a single file with no installer. Delete OddsTune.exe. Any reports you saved stay in your Documents folder until you delete them.

Stubborn Windows problem?

Odd$ Tune handles routine cleanup. If your PC is still slow, crashing or acting strangely, Favorable Odds offers computer cleanup and maintenance help.
